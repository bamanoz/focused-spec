## Why

Real model evaluations exposed an undisclosed focused-ID oracle and incomplete host-guidance discovery. These reject valid authoring choices or leave agents without their host's actual authoring contract; saved model results must remain immutable while fresh runs verify corrections.

## What Changes

- Accept one valid newly authored identity when neither the task nor existing source prescribes an ID; freeze it across proposal, apply, and publication.
- Preserve exact-ID judgment for pre-existing or explicitly requested identities and retain scope, evidence, mutation, integrity, and planning-boundary checks.
- Expose genuine installed Spec Kit authoring guidance as a discoverable local skill with provenance.
- Place BMad generated-capability identity guidance at the host integration boundary, preserving memlog-owned generation and external bindings.
- Provide actual OMP ACP read-only plan mode and explicit user-question/plan-confirmation transport for Agent OS; preserve approval and write-constraint gates and disclose unsupported capabilities rather than fabricate host validity.
- Make portable authoring phase-aware: defer executable registry/setup in explicitly planning-only turns, include repairs of selected assertions in evidence-sensitivity checks, and propose final metadata before approval.
- Correct native denial-wording judgment without weakening atomic outcome, stable binding, or generated-source checks.
- Select a named change's actual configured working scope and accept equivalent exact Go file/package selectors, retaining native source ownership and independent execution/mutation checks.
- Run fresh affected real-model evaluations after demonstrated corrections; do not rewrite historical scores.

None.

## Impact

Evaluation case metadata, checkpoints and completion judges, native-host provisioning, portable authoring skill, regression checks, and the agent-evals documentation. No production CLI/API or package-version change; no weaker evidence, approval, integrity, or certification gates.
